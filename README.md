# MIDI-Macropad
A MIDI macropad with 6 mechanical switches, per-key RGB, a rotary encoder and 7 capacitive touch keys. It is powered using a 2000mah battery and a TP4056 module. It is controlled by a Waveshare ESP32-S3-Zero. It can turn on and off using a rocker switch. This is a project for Half-Life at Hack club. This project's guide was made by [Kai Pereira](https://github.com/KaiPereira). I have made my adjustments from the original project like adding more switches, more LEDs, making a themed case and making it battery powered. As I already have the keycaps and rocker switches I will not include them in the Half-Life BOM, but they will be located in the MIDI_BOM.csv file for anyone who wants to make it from scratch.
